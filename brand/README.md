# Synqora identity — Graphite

The active original mark is [synqora-mark.svg](synqora-mark.svg): a restrained silver S inside a graphite app-icon box, with no Apple or other product marks.

[tools/export_brand.py](../tools/export_brand.py) renders the transparent mark, square preview, Windows ICO and Android adaptive/legacy launchers from the same vector geometry. Safe-area checks keep it away from masks and edges. In-app marks follow light/dark themes.

The earlier periwinkle raster master is retained for history and is no longer used for exports.
